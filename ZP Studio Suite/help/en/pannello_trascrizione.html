29 · ZP Transcription

One window, one path: from audio to text in the Teleprompter, which then follows splits and edits. Select audio items and see which stage is marked <- now.

Model and language

At the top, two dropdowns: Model (the list comes from ZP Speech, showing your installed models, for example large-v3, more accurate, or small, faster; Default is the engine's primary model) and Language (Italian, English, French, German, Spanish, Portuguese, Chinese, Japanese, Korean, Russian, Auto, or Other… to enter a language code, e.g. nl or yue). Whisper models (large-v3, small) know about 99 languages; Parakeet supports 25 European languages: if you pick Parakeet with an unsupported language, the window warns you. The selection is remembered and applies to Transcribe and Retranscribe. Each transcribed file remembers the settings used: in the item list it appears next to «SRT yes», for example (small en). To redo a file with another model: choose the model, select the item, and click Retranscribe….

Background processing

Transcribe, Retranscribe, and Translate work in the background: you can close the window, processing continues. The window title shows progress («transcribing 3 of 14»); upon completion, a macOS notification reports how many files succeeded. Reopening the window during processing shows live progress; if finished in the meantime, it collects results and, if you chose Follow the path, proceeds through Match and Send to teleprompter. A failed file does not stop others: the final summary shows the tally and details go to the console.

Translate (optional)

Translate… translates, only when requested, the SRT alongside selected items. From the menu choose the target language (starts immediately after confirmation), the Engine, and the Model; preferences are saved. The output is Name.en.srt alongside the original, with matching timestamps: the original remains untouched and an existing translation is not redone. In the menu, Engine: the agent available on your Mac: Auto (default) uses the first available among Codex (OpenAI via your ChatGPT account), Claude (Anthropic via your account), Qwen, OpenCode (configured service), and Ollama (local model: text stays on your Mac). Before starting, a prompt specifies which agent is used and where text is processed. Model: with Codex, Selected in Codex uses your configured model; with Ollama, the default installed model or your selection. While running, the button displays current file, processed lines, and elapsed time. If an agent skips or merges cues, the file is not written and details are logged to the console. In the item list, alongside SRT, existing translations appear (e.g. +it,en). In the Teleprompter: with Send to teleprompter (or Follow cuts), each translation becomes an additional flow, e.g. «Kevin · EN»: cues are attached to the original take markers, following cuts automatically. Select the flow from the Teleprompter dropdown; with All you see both original and translation together, and search finds translated lines navigating directly to the original audio cue.

The four stages

  1. Transcribe. Whisper (ZP Speech) creates an SRT alongside the WAV, with the same base name. Only missing files are transcribed: items already having an SRT or markers are left as they are, and the stage status indicates this («5 selected: 3 to transcribe, 2 already done»). If a file needs re-reading from scratch — after a glue, which preserves old marker times, or if timing has changed — the button becomes Retranscribe…: it asks for confirmation, clears take markers from selected items (Undo restores them), renames any existing adjacent SRT to .srt.bak-<date> without deleting it, and runs the path fresh. Teleprompter texts tied to old markers: untouched ones are removed, manually edited ones are muted. While running, the window displays «Working, not frozen» with elapsed time and an ETA. If the process stops without responding, a warning appears.
  2. Match from… Choose the source of dialogue cues; they become take markers on the item, in source time:
    • SRT alongside file: the standard case after stage 1. With multiple items, it never opens Finder: matches files having a matching SRT name, skips already matched items without prompts (to redo one, use Retranscribe…), and lists remaining items below (no SRT → Transcribe; markers but no SRT, typical after glue → kept as-is, Retranscribe if needed);
    • External or translated SRT: a file chosen by you for all selected items, even if an adjacent Whisper SRT exists (dubbing workflow: English audio, Italian SRT created via 26 SRT Tools). If items already contain markers, a single prompt asks whether to replace or keep them;
    • Project markers on timeline: uses script 14, without duplicates; prompts whether to delete them from timeline;
    • WAV cues → timeline markers: imports embedded WAV cues to timeline to manage them in REAPER; to embed them in items, then choose «Project markers».
  3. Send to teleprompter. Runs automatically after Match. Each marker becomes a text item on a hidden track Rythmo Band Testi <voice track name>. Manually corrected text is never overwritten. «Update now» reruns it whenever needed.
  4. Follow cuts. After 10 seconds of project inactivity, texts realign to audio, even after cuts and moves. The same switch exists in both Teleprompters, which usually stay open while working: keeping this window open is not required.

Follow the path executes only missing steps in order. Show text tracks reveals hidden text tracks.

In the Teleprompter

Under Text flow, browse with < >: beside individual flows, All reads all text tracks together (Read all), including hidden ones. The window title indicates which flow is active. Search operates on the selected flow; in All, it searches across the entire project.

Good to know

  • Transcription is a working guide: word timings may have small variances, the segment remains the listening reference.
  • Automatic transcription runs on macOS with ZP Speech installed. On other systems, create the SRT with your preferred Whisper setup, using the same name as the WAV, and start from «Match from…».
  • If a translated SRT uses video timecode (e.g. starting at 01:00:00) while the WAV starts at zero, configure the offset in SRT Tools: otherwise lines will fall outside the item.
  • Send to teleprompter scans all tracks: named reference or rehearsal markers will also become text.
