The ZP Studio Suite Toolbar

Seventeen buttons, and what each one does. Plus the ZP Colors toolbar, to color items and tracks.

Setting it up in REAPER

From the Action List run 32 Install toolbar and FX. It writes the ZP Studio Suite toolbar directly into REAPER toolbars, using the action identifiers of your REAPER (registering any scripts if needed), and installs FX chains and presets used by SOLO Recorder and Chain Builder. Then restart REAPER: before restarting do not open Customize toolbars. After restarting, open the toolbar via Switch toolbar or from 33 Welcome. The file MenuSets/ZP_StudioSuite.ReaperMenu remains available as a manual backup.

Active and closed indicators. Each icon features a dark tile with clear artwork that never changes: only the border changes. Gray = closed, bright = hover, cyan = window open (SOLO Recorder: red). A second click on an open tool's icon closes it.

Each icon includes three graphical states — closed, hover, open — which is why the PNG sprite is three times as wide as a single button (Retina 2x assets are also provided).

ZP Colors: click and color

Colors items and tracks with a single click. Available by default as a floating window: open and close it using the palette icon on the main toolbar. It docks neatly into your workspace.

If you prefer dedicated buttons permanently docked beside your transport, install the optional ZP Colors toolbar from 33 Welcome (line ZP Colors Toolbar, button Install) and select it via Switch toolbar. Both interfaces share current color mode settings seamlessly.

Workflow: select mode (Item, Track, or All: stays highlighted), select target items/tracks, and click a color swatch. Active mode is remembered across REAPER sessions. Any coloring operation is fully reversible via Ctrl/Cmd+Z.

ButtonFunction
ItemColors selected items. If a take has its own dedicated color, it is updated as well.
TrackColors selected tracks without touching items: items already having a custom color preserve it. Items without a color inherit the track color as standard in REAPER.
AllColors selected tracks and all items contained within them.
The 20 Colors
Click to apply according to active mode. Sixteen saturated palette tones plus white, black, gray, and bright red. Hovering over a color swatch displays its name.
Remove ColorRemoves colors according to active mode: items (and their takes), tracks, or both.

In Track or All mode, if no track is selected, the tracks of selected items are colored. If nothing is selected, a notification tooltip appears near mouse cursor (announced by OSARA). Every button has a corresponding action in the Action List (ZP_Colori_…) for custom hotkey assignment.

If a button does nothing

Each button triggers a script identified by an ID assigned by REAPER when registering the action. If a button points to a missing action (new script, moved folder, multiple installs), run 32 Install toolbar and FX and restart REAPER: it registers proper action IDs for your REAPER setup. If an icon still displays an older graphic, ReaPack has not yet synced updated assets: update packages and rerun tool 32.

When migrating from legacy setups, the action 27 Clean previous install safely archives legacy entries without deleting user media.
