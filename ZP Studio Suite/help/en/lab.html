These tools are separate packages of ZP Studio Suite. As of 2.6.9 they are no longer in beta; the requirements and limits below still apply.

ZP BrownSlope Dynamic Guard

Advanced, visible version of the Brown module already inside ZP BUS Chain and ZP Master Pro: a 4-band dynamic tonal guard for the end of a voice/music chain, before the final limiter. It gently steers long-term band energy toward a brown slope, then applies optional broadcast HPF/LPF guards.

  • MATCH applies a gentle static slope toward the brown target.
  • TOL (tolerance) is a dead zone: the dynamic part acts only on real deviations.
  • BIAS chooses Cut-only, Balanced or Gentle Boost; MID Focus gives more weight to the low-mid and high-mid zones.
  • Stereo and M/S analysis: L, R, Mid, Side, Width and L/R difference. Correction stays L/R linked so the stereo image does not change.
  • Header: IN, OUT and W/D (dry/wet) tiles. The ? next to them opens this page (Cue Navigator must be running).
  • Shared Bus v3.1 telemetry (2.6.9): publishes dynamic guard activity, W/D mix, and output trim to ZP Master Pro (CATENA tab) and 39 ZP Telemetry Engine.

Check it in real sessions before relying on it in a delivery.

ZP Click & Attack Softener

Three-stage transient/click cleaner and onset rounder with fixed automatic PDC (~14.7 ms at 48 kHz, zero latency jumps under automation):

  • 1A · MACRO CLICK: symmetric two-band pre/post attenuator for macro clicks (0.5–4 ms), with Consonant Protection to spare healthy p/t/k bursts before vowels.
  • 1B · MICRO-CLICK (v1.3 — STFT spectral engine + Freq Skew): switchable spectral stage (MICRO-CLICK: ON/OFF) using short-window STFT analysis (5.3 ms, 75% Hann-COLA overlap). The continuous Freq Skew control (-10..+10, LOW ↔ AIR) smoothly adjusts both the spectral floor (down to 380 Hz for low/wet clicks or up to 2.6 kHz for fine air ticks, always sparing the vocal fundamental) and band weighting across Macro and Micro-Click. The Micro % knob (slider20) is smoothed for artifact-free REAPER track automation so it acts strictly where needed.
  • 2 · ATTACK SOFTENER: rounds the first milliseconds of hard onsets strictly above the cutoff frequency (phase-coherent SVF crossover, keeping chest and body intact).
  • DELTA, D·MOLLA & Telemetry: global DELTA audition (30 s auto-off), spring-loaded D·MOLLA per-stage delta (MACRO, MICRO, or ATTACK), and Shared Bus v3.1 telemetry to ZP Master Pro and 39 ZP Telemetry Engine. Cue Navigator is optional and only needed by the ? button to open this guide.

Try it on copies of vocal recordings and compare with bypass or DELTA before using it in a delivery.

ZP Montaggio Parlato

Analyzes WAV items, transcribes them with ZP Speech and proposes an editing draft. The user makes the decisions; Apply creates splits and editing notes with one Undo.

Requires ZP Studio Suite and ZP Speech installed from 33 Welcome, with a ready provider: MacWhisper or local OpenAI Whisper with a model. It is currently tested on macOS. PDF import needs pdftotext (Poppler); other document formats use textutil. Clipboard paste is optional and requires SWS; without SWS, load the script from a file.

ZP Clean & Paint

The ReaPack package contains the REAPER actions, not the AI engine. It requires a separate ZP Voice Model Lab installation with CLI engines/rvc_local/zp_clean_paint_cli.py, Python in its local environment, data/paint_presets.json and the models needed by the selected mode.

Set the absolute path to the external project in ~/Library/Application Support/ZP_Clean_Paint/lab_root_path.txt (macOS) or %APPDATA%/ZP_Clean_Paint/lab_root_path.txt (Windows). PAINT also needs the RVC model and related index files; Welcome (33) checks for the CLI, Python and presets, not the models. The engine remains in development.
