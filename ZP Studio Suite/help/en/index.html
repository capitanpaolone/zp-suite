Overview and purpose

REAPER excels at recording and editing, but does not natively know the contents of your script. ZP Studio Suite bridges this gap:

  1. The text lives on the timeline. Every script line becomes a text item positioned exactly where spoken. It originates from SRT files, translations, automatic speech-to-text, or custom markers.
  2. Read text live while recording. The two Teleprompters display scrolling text locked to the playhead; screen reader users hear lines read aloud via OSARA or NVDA.
  3. Text tracks audio cuts. When script cues are linked to audio takes, splitting or moving audio clips moves the corresponding dialogue cues automatically. You can export updated subtitles at any point.

Complementing this core are dedicated production utilities: a remote recording panel (SOLO Recorder), automatic silence trimming, batch region organization for delivery renders, billing minute calculation, and automatic ZP audio chain construction with loudness monitoring.

Legacy track prefixes RythmoBand / Rythmo Band are retained internally to ensure seamless backward compatibility with older projects.

Core concepts

Text items and Rythmo Band Testi tracks
A dialogue cue is an empty text item with script content stored in its item notes. They reside on tracks named Rythmo Band Testi: main voice, reference languages (… REF, … ENG), or transcribed speakers. Transcription tracks are created hidden by default, visible inside the Teleprompter rather than cluttering the arrangement timeline (toggle visibility with Show text tracks in ZP Transcription).
Text flows
Selects which text track the Teleprompter displays. Switch using < > controls. All reads all text tracks combined (including hidden ones) in chronological sequence: invaluable during editing to search keywords across the entire project. The window title always indicates the active flow.
Project markers vs Take markers
A project marker sits on the global timeline ruler: moving audio items leaves the marker behind. A take marker is bound directly to an audio item take at a specific point in the speech waveform: moving or trimming the item moves the marker along with it. Cues are locked to take markers for this reason. Take markers are protected from accidental dragging: clicking a marker selects the item, and dragging requires Shift+drag (configured under Item markers in 33 Welcome).
Timeline time vs File source time
Video subtitles use timeline timecode (an SRT starts at the movie start point). Audio transcription uses file source time (a cue at 0:12 is at the 12th second of the WAV, wherever placed on the timeline). Video tools (01, 05, 08) work in timeline time; ZP Transcription and SRT from audio (29, 31) operate in file source time.
Follow cuts
Toggle available in ZP Transcription and both Teleprompters. When active, after 10 seconds of project inactivity, text items realign under their corresponding audio takes. Manually edited script lines are never overwritten.
Actor / character notes
For each role, the suite creates a voice track and a paired BB Note Personaggio - role track. Teleprompters read character colors and directorial notes from these tracks.
Sections and regions (delivery)
Batch deliveries use one region per delivery file and one marker per subfolder. Project Manager sets up regions and renders cleanly into Mixdown/<marker>/.

Starting workflows

Pick the workflow best matching your immediate production needs.

Dubbing / ADR to Picture

You have picture and an SRT script (or translation) to record in sync.

  1. Chain Builder, select ADR / Dubbing.
  2. ZP SRT → Video + SRT. For reference audio: Add language.
  3. Actor / Notes to define character roles.
  4. Open Vertical Teleprompter and record with SOLO Recorder.
  5. When done, export via ZP SRT → Export SRT.

Spoken Dialogue Editing

Podcasts, interviews, audiobooks: you have WAV files and need text to search and cut.

  1. Select audio items and open ZP Transcription: Follow the path.
  2. In Teleprompter, choose flow All and search keywords with Ctrl/⌘+F.
  3. Edit freely: with Follow cuts active, text follows take edits.
  4. After editing, SRT from audio exports finalized subtitles.

Recording Dubbing from Translated Script

Audio in source language, translated script in Word/Excel with timecode.

  1. SRT Tools: paste text to generate clean SRT (set offset if TC starts at 01:00:00).
  2. ZP Transcription → Match from… → External or translated SRT.
  3. Read inside Teleprompter while recording.

Batch Deliveries

Commercials, prompts, e-learning: dozens of named files in specific folders.

  1. Import Folders, or record via SOLO Recorder.
  2. Voice Cleaner to trim head/tails and split takes.
  3. Project Manager: regions, naming lists, render to Mixdown/.
  4. Project Viewer to verify, Minutes Report for billing.

ZP Transcription

Overview. Transfers speech to text into the Teleprompter and locks cues to audio takes. Follows a streamlined 4-stage path, showing current status of selected items.

When: you have spoken audio items (or external SRT / translation) and want to read and search text while editing.

  1. Transcribe — Whisper (ZP Speech) generates an SRT alongside the WAV file. Skips items that already have an SRT or take markers. To re-read a file from scratch — after a glue, or when audio timings changed — the button becomes Retranscribe…: prompts for confirmation, clears existing take markers from selected items (Undo restores them), archives existing SRT to .srt.bak-<date> without deleting, and runs the path fresh. Unaltered teleprompter cues disappear while manually edited lines are muted. Requires macOS with ZP Speech installed; on other systems generate SRT with external Whisper and proceed from stage 2.
  2. Match from… — Select dialogue cue source: adjacent SRT, external/translated SRT, timeline project markers, or WAV embedded cues.
  3. Send to teleprompter — Runs automatically after Match: each marker becomes a text item on hidden track Rythmo Band Testi <voice>. Update now refreshes at any time.
  4. Follow cuts — When active, after 10 s of idle time, text items realign to audio cuts.

Follow the path executes only missing steps in order. Full guide →

Vertical Teleprompter

Overview. Live scrolling prompter: displays script lines moving synchronously with playhead, highlighting the current cue, character colors, countdown lead-in timer, and directorial notes. Supports in-place text corrections.

When: in the voice booth while reading; during editing to locate and tweak dialogue cues. Ideal format for multi-voice scripts.

The right side panel is grouped logically: top controls for daily operations, Text and Reading, and collapsible Theme and Notes and Tracks sections (state is remembered). Toggles ☑ turn options on or off. Click > to collapse the sidebar.

Text and Reading

  • Flow (dropdown ▾): select which text track to read (main, reference languages, individual voice tracks, or All).
  • Font Size: scale text readability.
  • Reading Guide (Top / Third / Center): vertical playhead anchor inside the prompter window. Top shows upcoming text below; Center focuses on current line while leaving space above for a video window.
  • Continuous Scrolling: on, text glides continuously with the timeline like a rythmo band; off, text flips page-by-page, cue by cue.
  • Word by Word: highlights words progressively across each spoken line.
  • Countdown: numeric countdown before each incoming dialogue cue.
  • Show Timecode, and in Theme: Mode (dark, medium, light), Contrast (soft, full), Speaker Colors (distinct hue per character/voice track).

Editing and Notes

  • Search (Ctrl/⌘+F): prefix and keyword search (e.g. hijac finds hijacking). Case and accent insensitive. Quote phrases for exact matching. Result list displays timecode, text, and track in All mode; click or use ↑/↓, <, > to jump.
    Replace: expands replace field (Tab jumps between inputs). Replace matches whole words only and respects exact accents. Click Replace to step through occurrences; All replaces across the project with a single Undo step. Only teleprompter item notes are altered: take markers and source SRT files remain untouched.
  • Double click on any cue opens inline editor. Enter saves, Shift+Enter inserts newline, Esc cancels.
  • Studio/Edit Mode: stops playback and unlocks free text navigation; Moves timeline controls whether scrubbing text also moves the REAPER edit cursor.
  • + Note: adds a director's note at edit cursor. Notes Panel displays chronological list of notes, following playback automatically. Clicking jumps to note position, double click edits; OK marks note completed (green badge); × deletes note after confirmation. Undoable via Ctrl/⌘+Z.
  • Follow cuts: toggles automatic realigning.
  • Notes visible / Prompter tracks visible: toggles arrangement visibility of notes and text tracks. + Line adds a new cue item at current position.

OSARA Menu: accessible popup menu containing all toolbar options with identical labels. Screen reader playback actions are handled separately by actions 09-12.

Horizontal Teleprompter

Overview. Displays script scrolling horizontally right-to-left across the screen, mimicking a traditional dubbing rythmo band: lines pass beneath a central reading cursor with timecode.

When: single-voice narration requiring tight picture sync (lip-sync dubbing, commercial voiceovers, video narration).

  • Scale / Speed (pixels per second) and Font Size.
  • Speech Lead (0-10 s): announces cues in advance via OSARA or NVDA for screen reader users.
  • Shared feature set: Text flow with All, Search, Studio/Edit, inline editing, Follow cuts.

Markers

Overview. Single panel with two tabs managing markers linked to selected items.

Create from Items
Places a timeline project marker at the start of each selected item: empty, named, or numbered (NAME 001, 002…). Video TC names markers using video or region timecode. Use to mark start of takes or scenes before building regions.
Embed into Items
Embeds project markers falling within selected items as audio take markers, preserving name, position, and color. Choose All selected or First only, and optionally clear them from the timeline ruler. Works on trimmed or time-stretched items. Service markers: markers starting with # (e.g. #scene 2), action markers (!), SOLO Recorder markers (SOLO_MARK_…, OK_…, BAD_…), and empty markers are never converted into dialogue text or exported. Use when cues were marked manually on the timeline and now need to follow audio edits.

Actor / Notes

Overview. Role setup tool. Enter character names separated by commas (Narrator, Alice, Bob): creates a voice track and a paired child BB Note Personaggio track for each character.

When: starting a multi-voice dubbing or narration session before launching the Teleprompter. The prompter extracts character colors and notes from these tracks.

SOLO Recorder

Overview. Recording remote control allowing you to track without switching window focus back to REAPER. Enforces exclusive track arming, numbers take regions (Take 001, 002…) on each stop, and handles markers, retakes, inserts, and alternate takes across dedicated tracks (MAIN, INSERTS, RETAKES, ALT). Features Mini, Compact, and Expanded views. Live hardware input metering in dB, pre-roll in seconds, and built-in marker naming. The web icon launches a Web Remote in your browser for iPad/phone control.

When: recording voiceover or dubbing sessions, especially unattended solo tracking. Supports SOLO Session (creates ZP SOLO SESSION folder) and Remote Control (controls pre-existing tracks). Full control guide →

Voice Cleaner (Silence Split)

Overview. Detects spoken speech in audio takes and trims room tone: removes head/tail silence or splits long files into individual phrases, applying configurable pre/post-roll margins and crossfades.

When: cleaning raw voice takes or splitting long sessions into individual phrases before creating delivery regions.

  1. Select items and click ANALYZE: inspects waveform without modifying items. Check Audio read status.
  2. PREVIEW draws temporary red preview regions; CLEAR PREVIEW removes them.
  3. APPLY performs cuts within a single Undo step.

Modes: Head/tail trim or Split internal silences; Original position or Sequence spacing. Presets: VO Smart, Gentle, Tight, Manual. Detailed guide →

Import Folders

Overview. Imports entire folder structures of audio or video files in order onto the timeline. Selected parent directory subfolders become timeline section markers, and media files become named regions with configurable gaps.

When: importing batches of organized files (e.g. 40 commercial spots across 4 languages) to deliver in the same directory structure. Render is triggered via Project Manager.

Project Manager

Overview. Delivery manager: creates export regions (one per take/file) and routes batch renders to correct destinations without altering original audio takes.

When: delivering numerous files requiring strict naming conventions and directory structures.

Create Regions

  • Source: Items (selected), Tracks (selected), Folder+, All. Only valid audio/video items are processed; empty items, notes, and MIDI are skipped. Video includes video files; Skip muted ignores muted clips.
  • File Gap: silence duration triggering a new region. Head/Tail Padding expands region boundaries without moving audio.
  • Naming: paste a list of names (one per line or ; separated) to apply sequentially; No. + name prefixes sequential numbers. Double-click to rename in preview.
  • Create Regions. Remove Export clears only regions created by this tool.

Prepare Mixdown

  • Section Selection: chooses marker section; encompasses regions up to the next marker.
  • Marker Lanes: Lane 1 = Mixdown/<marker>/; Lane 2 = subfolder; Lane 3+ = standard markers. Regions outside Lane 1 are excluded.
  • Quick format settings (WAV/MP3, mono/stereo, sample rate). Render configures output path, $region wildcard, and opens REAPER Render dialog. + Queue queues batch jobs.
  • Log: writes history to Mixdown/Mixdown_History.csv. Index: creates Mixdown_Index.csv in section folders verifying rendered files.

Project Viewer

Overview. Project table of contents: displays all markers and regions chronologically on separate rows. Click to navigate, double-click to rename, spacebar to audition. Selecting regions sets render bounds for Ctrl/⌘+Alt+R, and Minutes Report counts selections.

When: verifying section and region names prior to final render, or navigating large multi-hour timelines. Can be docked beside the arrange window.

Voice Minutes Report

Overview. Calculates total voice minutes: exact duration, rounded billable minutes, and estimated word counts. Counts selected regions, all regions, selected items, or tracks.

When: preparing billing invoices, client estimates, or auditing character workloads.

  • Only items with real audio takes are counted. Skip muted excludes muted clips.
  • Copy + HTML copies summary and generates HTML delivery report.
  • Add to History: updates cumulative project history without duplicating entries.
  • Save Session: creates standalone snapshot report.

Probe Guard

Overview. Because the Probe measures actual output loudness, it must remain the last plugin on the bus. Probe Guard checks once per second that Voice Probe and Music Probe occupy the final slot, moving them back if plugins are inserted after them.

When: runs automatically with Chain Builder. Keeping the window open keeps the guard active.

ZP Shared Bus Plugins

ZP plugins communicate via shared memory (gmem=ZPVoiceoverSharedBus): each plugin reports real-time activity, the Probe measures real bus audio output, and Master Pro compares results against the target loudness engine to offer advisory suggestions. No plugin ever alters another plugin's DSP parameters. Installed via ReaPack in Effects/ZP_Paolo Balestri JSFX.

ZP BUS Chain

Purpose: Primary voice bus processor (dialogue, voiceover, dubbing). Combines Expander/Gate, De-Esser/Air, 1175, LA-2A, and Major Tom compressors, analog Brown stage, and safety Limiter.

Where to place: On Voice Bus (voice folder or master dialogue bus).

Key controls: Expander Thresh/Range, compressor RED/MAKEUP, Brown Drive/Mix, High Air, Limiter Ceiling/Release, module toggles. Broadcasts full telemetry to Shared Bus.

ZP Harmonic Space Carver

Purpose: Mix/music bed ducking assistant. Dynamically creates spectral and volume room under dialogue using voice-guided multibanda carving and VCA ducking, synchronized via timeline cues (#HSC).

Where to place: On Music Bus. Chain Builder places it here for Podcast and Commercial Spot profiles.

Key controls: VOICE sidechain inputs (3/4, 5/6, 7/8), Min Duck & Max Duck, VCA Ceiling, Glue, Carver bands (B1-B4), and Cue bar (#HSC) with automatic audio anchor tracking.

ZP Spoken Finish

Purpose: Optional harmonic voice enhancer. Adds body, even/odd harmonics, presence, air, and VOG (Voice of God) sub-bass for authoritative broadcast density.

Where to place: On Voice Bus after BUS Chain, or on individual voice tracks.

Key controls: Harmonic Amount (Even/Odd), Body, Air/Presence, VOG Sub-bass, Dynamic Drive. Reports telemetry for Master Pro comparison.

ZP Stagekeeper Dialogue Director

Purpose: Intelligent dual-mic (L/R) dialogue automixer for podcasts, interviews, and roundtables. Detects dominant speaker and smoothly attenuates acoustic bleed on the listening mic without abrupt gating.

Where to place: On dual-microphone stereo track (or preceding voice sum bus).

Key controls: Input Trim L/R, Speech Detect thresholds, Delta margin, Response (Attack, Release, Hold, Lookahead, Softness HARD ↔ SMOOTH), Background Attenuation, monitor MIX / CHECK L / CHECK R, built-in Limiter.

ZP Subliminal Presence Layer White

Purpose: Psychoacoustic micro-modulation presence layer (shaped white spectrum). Eliminates eerie digital silence between voice phrases, providing subtle natural continuity.

Where to place: End of voice processing chain or parallel voice auxiliary track at a gentle level.

Key controls: Level, Color/Filter, Modulation Depth, Voice Envelope Ducking, Mute/Audition.

ZP Voiceover Unified Chain

Purpose: Integrated all-in-one channel strip for single tracking and voice capture. Packs high-pass filter, noise gate, de-esser, 1175/LA-2A/Major Tom compression, and safety limiter into a single interface.

Where to place: On recording microphone tracks or voice input templates.

Key controls: Input Gain, Gate Threshold, Compressor Amount/Mix, Tone Tilt, Output Ceiling. Sends gain reduction data to Shared Bus.

ZP Master Pro

Purpose: Master bus supervisory intelligence. Analyzes multi-plugin telemetry and Probe readings against target loudness profiles (ADR, Voiceover, E-learning, Podcast, Spot, Radio).

Where to place: On final project Master Bus.

Key controls: Target Profile selector, Navigator (MANUAL / AUTO SIMPLE / AUTO COMPLEX), causal Measure Engine display, [Target] thresholds, bus status LEDs.

ZP Reference Tone Mirror EQ Pro

Purpose: Comparative matching equalizer. Compares real-time voice spectrum against broadcast target curves or captured reference audio files to assist tonal balance.

Where to place: On Voice Bus or Master track during timbre mastering.

Key controls: Learn Reference, Target Curves (Neutral, Warm, Bright, Broadcast), Amount/Matching Gain, spectral smoothing, difference display.

ZP Loudness Meter Multichannel

Purpose: High-precision loudness meter conforming to ITU-R BS.1770-4 and EBU R128 standards, from stereo up to 16 surround channels.

Where to place: At end of master chain or across any multichannel monitor bus.

Key controls: Numerical & bar meters for Integrated LUFS, Short-term LUFS, Momentary LUFS, LRA (Loudness Range), True Peak dBTP, measure reset, standard target scales (-23 EBU, -24 ATSC, -14 Streaming).

ZP Oscilloscope 16ch

Purpose: Multichannel real-time waveform oscilloscope supporting up to 16 synchronized channels, for analyzing envelope, transient peaks, and acoustic phase relationships.

Where to place: On multichannel tracks or monitor aux bus.

Key controls: Timebase (ms/div), Vertical Gain/Zoom, trigger modes (Free, Normal, Single, Channel), overlay or split channel views.

ZP Voice-Music Probe

Purpose: Passive transparent shared bus metering probe. Never alters audio; accurately measures RMS, True Peak, crest factor, density, brightness, and speech activity.

Where to place: Absolute final slot on Voice Bus (Voice role) and Music Bus (Music role), guarded by Probe Guard.

Key controls: Role switch (Voice / Music), real-time meter display, Shared Bus gmem activity indicator.

Standalone SRT Tools

Accessible from ZP SRT or directly via the Action List.

01 · Video + SRT

Imports video and paired subtitle files: sets up video track and Rythmo Band Testi track with one text item per cue. Modes: Single, Folder batch, SRT/VTT only, Empty text track.

05 · SRT Management

Replaces or supplements subtitles in existing sessions: Replace SRT, Add language/reference, Batch matching. Archives previous items onto BKP backup tracks.

08 · Export SRT

Exports finalized SRT files from timeline text items. Times are calculated relative to each video or region start point, ready for distribution.

13 · SRT Item Info

Read-only inspector window that updates automatically when clicking different timeline items. Displays cue origin, binding status, and full text.

26 · SRT Tools (from text or translation)

Local browser utility to convert plain text scripts containing timecode into clean SRT files, with offset calibration.

31 · SRT from Audio

Exports SRT files from take markers embedded inside selected audio items, capturing manual adjustments made in REAPER.

28 · Link Markers

Underlying engine for ZP Transcription stage 2: embeds SRT cues as take markers inside audio items. Details →

34 · ZP Command Sets (Keyboard Shortcuts)

Switch keyboard shortcut layouts with one click: video editing layout, Pro Tools or Logic key habits, or custom setups. Open from the keyboard toolbar icon:

  • Activate: switches to selected set. Prompts to restart REAPER immediately or on next launch.
  • Inspect Layout: displays complete key-to-action list.
  • AI Explanation (optional): generates plain-English summary of shortcut layout using local or cloud AI agents via ZP Speech.
  • Automatic Backup: archives current keys to Automatic Backup before any switch.
  • Save Current Keys… / Import File…: manage custom .ReaperKeyMap files.

35 · ZP Colors (Click & Color)

Color palette tool: three modes — Item, Track, All —, twenty custom colors, and Remove Color. Fully reversible with Ctrl/Cmd+Z. Available as floating window or optional toolbar ZP Colors.

Installation & Optional Components

Install and update via ReaPack: Extensions → ReaPack → Import repositories, paste https://github.com/capitanpaolone/zp-suite/raw/master/index.xml, browse packages, and install ZP Studio Suite.

33 Welcome (Installation Check): opens automatically on first tool launch or from the Action List. Verifies installed components:

  • Suite language: side-by-side buttons (Italiano | English). Applies immediately to windows, messages and guides opened after.
  • REAPER language: dropdown menu showing the active language pack (or Original (English)) from REAPER/LangPack. Selecting a pack shows a restart button to apply immediately.
  • Toolbar & FX: Install runs tool 32. Restart REAPER to finalize.
  • Cue Navigator (Harmonic Space Carver helper): starts helper on launch.
  • ZP Speech (macOS): powers Whisper transcription and translation.
  • SWS, js_ReaScriptAPI, OSARA: optional enhancements.
  • Item Markers: sets mouse modifier to protect take markers from accidental displacement.

Toolbar & FX: run 32 Install ZP Toolbar after installation to register action IDs and install FX chains. Details in toolbar guide.
