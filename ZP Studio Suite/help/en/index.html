Overview and purpose

REAPER excels at recording and editing, but does not natively know the contents of your script. ZP Studio Suite bridges this gap:

  1. The text lives on the timeline. Every script line becomes a text item positioned exactly where spoken. It originates from SRT files, translations, automatic speech-to-text, or custom markers.
  2. Read text live while recording. The two Teleprompters display scrolling text locked to the playhead; screen reader users hear lines read aloud via OSARA or NVDA.
  3. Text tracks audio cuts. When script cues are linked to audio takes, splitting or moving audio clips moves the corresponding dialogue cues automatically. You can export updated subtitles at any point.

Complementing this core are dedicated production utilities: a remote recording panel (SOLO Recorder), automatic silence trimming, batch region organization for delivery renders, billing minute calculation, and automatic ZP audio chain construction with loudness monitoring.

Legacy track prefixes RythmoBand / Rythmo Band are retained internally to ensure seamless backward compatibility with older projects.

Core concepts

Text items and Rythmo Band Testi tracks
A dialogue cue is an empty text item with script content stored in its item notes. They reside on tracks named Rythmo Band Testi: main voice, reference languages (… REF, … ENG), or transcribed speakers. Transcription tracks are created hidden by default, visible inside the Teleprompter rather than cluttering the arrangement timeline (toggle visibility with Show text tracks in ZP Transcription).
Text flows
Selects which text track the Teleprompter displays. Switch using < > controls. All reads all text tracks combined (including hidden ones) in chronological sequence: invaluable during editing to search keywords across the entire project. The window title always indicates the active flow.
Project markers vs Take markers
A project marker sits on the global timeline ruler: moving audio items leaves the marker behind. A take marker is bound directly to an audio item take at a specific point in the speech waveform: moving or trimming the item moves the marker along with it. Cues are locked to take markers for this reason. Take markers are protected from accidental dragging: clicking a marker selects the item, and dragging requires Shift+drag (configured under Item markers in 33 Welcome).
Timeline time vs File source time
Video subtitles use timeline timecode (an SRT starts at the movie start point). Audio transcription uses file source time (a cue at 0:12 is at the 12th second of the WAV, wherever placed on the timeline). Video tools (01, 05, 08) work in timeline time; ZP Transcription and SRT from audio (29, 31) operate in file source time.
Follow cuts
Toggle available in ZP Transcription and both Teleprompters. When active, after 10 seconds of project inactivity, text items realign under their corresponding audio takes. Manually edited script lines are never overwritten.
Actor / character notes
For each role, the suite creates a voice track and a paired BB Note Personaggio - role track. Teleprompters read character colors and directorial notes from these tracks.
Sections and regions (delivery)
Batch deliveries use one region per delivery file and one marker per subfolder. Project Manager sets up regions and renders cleanly into Mixdown/<marker>/.

Starting workflows

Pick the workflow best matching your immediate production needs.

Dubbing / ADR to Picture

You have picture and an SRT script (or translation) to record in sync.

  1. Chain Builder, select ADR / Dubbing.
  2. ZP SRT → Video + SRT. For reference audio: Add language.
  3. Actor / Notes to define character roles.
  4. Open Vertical Teleprompter and record with SOLO Recorder.
  5. When done, export via ZP SRT → Export SRT.

Spoken Dialogue Editing

Podcasts, interviews, audiobooks: you have WAV files and need text to search and cut.

  1. Select audio items and open ZP Transcription: Follow the path.
  2. In Teleprompter, choose flow All and search keywords with Ctrl/⌘+F.
  3. Edit freely: with Follow cuts active, text follows take edits.
  4. After editing, SRT from audio exports finalized subtitles.

Recording Dubbing from Translated Script

Audio in source language, translated script in Word/Excel with timecode.

  1. SRT Tools: paste text to generate clean SRT (set offset if TC starts at 01:00:00).
  2. ZP Transcription → Match from… → External or translated SRT.
  3. Read inside Teleprompter while recording.

Batch Deliveries

Commercials, prompts, e-learning: dozens of named files in specific folders.

  1. Import Folders, or record via SOLO Recorder.
  2. Voice Cleaner to trim head/tails and split takes.
  3. Project Manager: regions, naming lists, render to Mixdown/.
  4. Project Viewer to verify, Minutes Report for billing.

ZP Transcription

Overview. Transfers speech to text into the Teleprompter and locks cues to audio takes. Follows a streamlined 4-stage path, showing current status of selected items.

When: you have spoken audio items (or external SRT / translation) and want to read and search text while editing.

  1. Transcribe — Whisper (ZP Speech) generates an SRT alongside the WAV file. Skips items that already have an SRT or take markers. To re-read a file from scratch — after a glue, or when audio timings changed — the button becomes Retranscribe…: prompts for confirmation, clears existing take markers from selected items (Undo restores them), archives existing SRT to .srt.bak-<date> without deleting, and runs the path fresh. Unaltered teleprompter cues disappear while manually edited lines are muted. Supports both MacWhisper and local OpenAI Whisper (isolated multi-platform Python runtime).
  2. Match from… — Select dialogue cue source: adjacent SRT, external/translated SRT, timeline project markers, or WAV embedded cues.
  3. Send to teleprompter — Runs automatically after Match: each marker becomes a text item on hidden track Rythmo Band Testi <voice>. Update now refreshes at any time.
  4. Follow cuts — When active, after 10 s of idle time, text items realign to audio cuts.

Speech engines (ASR) & local models: ZP Speech requires specialized ASR models (Whisper) to produce exact word timestamps (word_timestamps) essential for the Prompter; LLMs (Ollama, OpenCode) only process text and in ZP are dedicated to translation, not audio transcription. Pre-existing Whisper models are automatically detected from standard system cache (~/.cache/whisper) or custom folders via ZP_WHISPER_MODELS_DIR, with zero hidden downloads during sessions. Follow the path executes only missing steps in order. Full engine & workflow guide →

Vertical Teleprompter

Overview. Live scrolling prompter: displays script lines moving synchronously with playhead, highlighting the current cue, character colors, countdown lead-in timer, and directorial notes. Supports in-place text corrections.

When: in the voice booth while reading; during editing to locate and tweak dialogue cues. Ideal format for multi-voice scripts.

The right side panel is grouped logically: top controls for daily operations, Text and Reading, and collapsible Theme and Notes and Tracks sections (state is remembered). Toggles ☑ turn options on or off. Click > to collapse the sidebar.

Text and Reading

  • Flow (dropdown ▾): select which text track to read (main, reference languages, individual voice tracks, or All).
  • Font Size: scale text readability.
  • Reading Guide (Top / Third / Center): vertical playhead anchor inside the prompter window. Top shows upcoming text below; Center focuses on current line while leaving space above for a video window.
  • Continuous Scrolling: on, text glides continuously with the timeline like a rythmo band; off, text flips page-by-page, cue by cue.
  • Word by Word: highlights words progressively across each spoken line.
  • Countdown: numeric countdown before each incoming dialogue cue.
  • Beep before the cue: during playback or recording it plays two beeps, 3 and 2 seconds before the cue starts; the last second stays silent, as in the Dubbertools prompter. Meant for those who cannot see the countdown. Switch it on and off from the panel; when it is on, Beep volume appears (−36 to −6 dB, in 3 dB steps) and every change plays the beep at the new level. With OSARA the same entries are in the accessible menu (21, 22, 23). The beep goes to the main outputs of the audio interface and is not recorded in the project; it needs the SWS extension.
  • Incoming cue TC alert: during the three seconds before a cue starts, the timecode box at the top flashes yellow. Works with any reading guide position (top, third, center). If Show Timecode is off, the box appears only while the alert is active.
  • Show Timecode, and in Theme: Mode (dark, medium, light), Contrast (soft, full), Speaker Colors (distinct hue per character/voice track).

Editing and Notes

  • Search (Ctrl/⌘+F): prefix and keyword search (e.g. hijac finds hijacking). Case and accent insensitive. Quote phrases for exact matching. Result list displays timecode, text, and track in All mode; click a result or its Go → button to jump to the word and highlight it in the Teleprompter, or use ↑/↓, <, > to jump.
    Replace: expands replace field (Tab jumps between inputs). Replace matches whole words only and respects exact accents. Click Replace to step through occurrences; All replaces across the project with a single Undo step. Only teleprompter item notes are altered: take markers and source SRT files remain untouched.
  • Double-click a word to select it in blue without opening the editor or changing transport/timeline position. Right-click to choose Edit text…, Add reminder on this word… or Split before this word. The selected word remains the target even as text scrolls. In the editor, Enter saves, Shift+Enter inserts a blank pause row in the same text, Esc cancels. The editor opens with the cursor at the selected word and shows that line, including in long scripts. For timed text with Recalculate timeline item duration enabled, blank rows add reading space and time to the same item. No separate item is created. When only pauses change, the previous duration is increased or reduced by the time of the added or removed rows. Leading and trailing pauses are retained. In notes, Shift+Enter remains a normal newline.
  • + Timed text: opens an editor for a full script you can paste, then creates one item at the current position (playhead while playing, edit cursor while stopped; a time selection uses its start). The initial pace is 120 words per minute. The −/+ buttons adjust it by 10 words per minute; while the player is inside a timed item, they recalculate that item's duration. Duration accounts for words and blank lines; the vertical Teleprompter layout keeps the reading point centered. The same item also appears in the horizontal Teleprompter, where it crosses the reading bar. In the vertical window, you can scroll by hand while reading: the text stays where you put it until you press Reposition to playhead, click the amber banner, or press Esc to reattach. Space retains its Play/stop function. The words-per-minute value appears above the −/+ buttons so it does not cover them. The banner remains visible when Tab hides the sidebar. +/− and Alt+wheel adjust words per minute; a thin bar shows item progress. Reading focus toggles the reading-zone tint and horizontal badges show character names. OSARA choices 1–17 are unchanged: 18 Load file…, 19 Reposition to playhead, 20 Reading focus on/off. At the end, scrolling stops; playback and recording continue.
  • Studio/Edit Mode: stops playback and unlocks free text navigation; Moves timeline controls whether scrubbing text also moves the REAPER edit cursor.
  • + Note: adds a director's note at edit cursor. Notes Panel shows unfinished notes first, then completed notes; each group is chronological. Scroll with the wheel; the panel follows the current note automatically until you scroll by hand. Clicking jumps to note position, double click edits; double click empty space in the panel to add a note at the current edit cursor, or right click and choose New Note beside the pointer. OK marks note completed (green badge); × deletes note after confirmation. Undoable via Ctrl/⌘+Z.
  • Notes linked to their cue: each note stays attached to the cue it was placed on (or the nearest one within 10 seconds). Move the cue on the Timeline and the note follows; delete the cue and the note goes with it, and REAPER's Undo brings both back. If you split a cue, the note stays on the part that contains it. Moving a note by hand attaches it to the cue where you drop it. Links are updated while the Prompter is open.
  • Command bar: always dark; Theme (dark, medium, light) only changes the script page.
  • Follow cuts: toggles automatic realigning.
  • Notes visible / Prompter tracks visible: toggles arrangement visibility of notes and text tracks. The old + Line button, which created a separate «TESTO» item, has been removed. Use Shift+Enter in the editor for pauses; OSARA choice 11 reminds you of this shortcut.

OSARA Menu: accessible popup menu containing all toolbar options with identical labels. Screen reader playback actions are handled separately by actions 09-12.

Clicking a cue selects it without moving the timeline, including when Moves timeline is enabled. Double-clicking selects a word; right-click and choose Edit text… to open the editor without stopping transport or changing its position. Use the wheel, scrollbar or search to navigate explicitly. This applies to both Teleprompters.

Split a script at the selected word

In either Teleprompter, double-click the word that should start the next piece, then right-click → Split before this word. The left item keeps the preceding text; the right item contains the selected word and the remainder, and is selected for manual movement in the timeline. The full script is not duplicated. The split uses the word’s estimated time in the original reading plan; the REAPER cursor stays in place. Both items remain adjacent and their combined duration is unchanged.

Joining split cues: when one line is spread over several items, right-click the text in the Teleprompter → Join with the next cue, or select the pieces on the text track in the timeline and choose Join the cues selected in the timeline. The first item stays, with the texts in a row separated by a space and its length reaching the end of the last one; the others are removed. One Ctrl+Z undoes it. The 38 ZP Unisci Battute action does the same on the selected items without opening the Teleprompter (handy with a shortcut and with OSARA).

The command is available only for standalone timed text, without audio takes or a ZP_SYNC link. Subtitles managed by Follow cuts retain their existing workflow. Audio and other items are not split or moved. Use the Teleprompter command for this operation: REAPER’s standard Split does not partition script contents.

Word and pause timing is preserved across both pieces, including pieces shorter than five seconds; the item boundary adds no pause. Reminders move to the piece containing their word and their text offsets are adjusted, while timeline markers stay where they were. Colors, pace and highlights are retained. One REAPER Undo reverses the operation; Redo restores it. Text is validated again before splitting: if it has changed since selection, select the word again. Subsequent text or pace edits rebuild timing using the editor settings.

Actual pauses and script reminders

In timed text, Shift+Enter inserts a blank row with its own pause interval: scrolling holds at the last spoken word and highlighting does not advance until the pause ends. Leading and trailing blank rows are respected. The horizontal band pauses as well. A single imported newline remains an ordinary line break. Existing saved blank rows are recognized without reinserting them. Words per minute determines the blank-row pause; the timeline item retains its current duration.

Reminders: in the vertical Teleprompter reading view, right-click a word and choose Add reminder on this word…. Enter a name: a normal REAPER marker is created at the timeline edit cursor. An amber dot and underline identify the word in the script. Move the marker freely in the timeline, including outside the item: it is an editing reminder (“this word goes there”), not a synchronization point. It never changes scrolling or moves/splits items. Renaming or renumbering the marker preserves its link to the word.

Unlink this text’s markers in the right-click menu removes script references while keeping timeline markers. Deleting a marker in REAPER removes its script indicator without recreating it. Text inserted or removed before a word updates its reference when saved; deleting the word leaves the timeline reminder in place without assigning it to another word. Marker creation and unlinking support REAPER Undo.

Script editor and file import

Load file… in the toolbar or Ctrl/⌘+L opens new timed text from .docx, .odt, .rtf or UTF-8 .txt. Within the editor, a file is inserted at the cursor or replaces the selection. Word and LibreOffice are not required: Office document XML is read from ZIP using unzip on macOS/Linux or PowerShell/.NET on Windows. Formatting is discarded and blank paragraphs remain pauses. Enable Import bold/highlighted text to add marked terms to Teleprompter highlights when saving.

The text viewport has mouse wheel and scrollbar support; typing and pasting keep the cursor visible. Save and Cancel stay at the bottom. Paste clean text (Ctrl/⌘+V) normalizes spacing, quotes and dashes while preserving accents. Without SWS it uses pbpaste, Get-Clipboard, or wl-paste/xclip/xsel on Linux. Clean spacing also reduces repeated blank lines to one pause; Join PDF lines joins wrapped lines while retaining paragraphs. Tools includes sentence splitting, lowercase/UPPERCASE/sentence case on the selection, and Undo edit (Ctrl/⌘+Z). Highlight (Ctrl/⌘+E) marks the selection or current word. Esc also discards unsaved highlights.

The footer shows words, pauses and estimated duration, with a pace of 40–240 words per minute. When editing timed text, disable Recalculate timeline item duration to preserve manual timing. Saving without changes preserves timing as well. The vertical window estimates pauses from wrapped lines; the horizontal window uses script lines when creating or recalculating an item.

Horizontal Teleprompter

Overview. Displays script scrolling horizontally right-to-left across the screen, mimicking a traditional dubbing rythmo band: lines pass beneath a central reading cursor with timecode.

When: single-voice narration requiring tight picture sync (lip-sync dubbing, commercial voiceovers, video narration).

  • Scale / Speed (pixels per second) and Font Size.
  • Speech Lead (0-10 s): announces cues in advance via OSARA or NVDA for screen reader users.
  • Shared feature set: Text flow with All, Search, Studio/Edit, inline editing, Follow cuts.

  • Notes linked to their cue: here too each note follows its cue when you move it and goes away with it when you delete it, as in the Vertical Teleprompter.

Markers

Overview. Single panel with two tabs managing markers linked to selected items.

Create from Items
Places a timeline project marker at the start of each selected item: empty, named, or numbered (NAME 001, 002…). Video TC names markers using video or region timecode. Use to mark start of takes or scenes before building regions.
Embed into Items
Embeds project markers falling within selected items as audio take markers, preserving name, position, and color. Choose All selected or First only, and optionally clear them from the timeline ruler. Works on trimmed or time-stretched items. Service markers: markers starting with # (e.g. #scene 2), action markers (!), SOLO Recorder markers (SOLO_MARK_…, OK_…, BAD_…), and empty markers are never converted into dialogue text or exported. Use when cues were marked manually on the timeline and now need to follow audio edits.

Actor / Notes

Overview. Role setup tool. Enter character names separated by commas (Narrator, Alice, Bob): creates a voice track and a paired child BB Note Personaggio track for each character.

When: starting a multi-voice dubbing or narration session before launching the Teleprompter. The prompter extracts character colors and notes from these tracks.

SOLO Recorder

Overview. Recording remote control allowing you to track without switching window focus back to REAPER. Enforces exclusive track arming, numbers take regions (Take 001, 002…) on each stop, and handles markers, retakes, inserts, and alternate takes across dedicated tracks (MAIN, INSERTS, RETAKES, ALT). Features Mini, Compact, and Expanded views. Live hardware input metering in dB, pre-roll in seconds, and built-in marker naming. The web icon launches a Web Remote in your browser for iPad/phone control.

When: recording voiceover or dubbing sessions, especially unattended solo tracking. Supports SOLO Session (creates ZP SOLO SESSION folder) and Remote Control (controls pre-existing tracks). Full control guide →

ZP Remote (remote dubbing)

Overview. Prepares in REAPER the material a performer needs to record remotely and brings what they deliver back into the project. The recording itself happens on an external service, Dubbertools, which the performer opens in a browser: the Suite only handles the two ends, the outgoing package and the incoming delivery.

When: a dubbing actor or voice talent records from home and you want their takes already in place on the Timeline.

  • ZP Remote · Package (also on the toolbar): builds the package to upload to Dubbertools, with video, audio guide and loops taken from the project.
  • Import delivery: brings the performer's recorded files into the project, on their character's track. Import WAV without manifest is for when only the audio files arrive.
  • Set project ID: links the REAPER project to the project on Dubbertools, so deliveries return to the right project.

The service is still in development: this section will be expanded once Dubbertools is complete.

Voice Cleaner (Silence Split)

Overview. Detects spoken speech in audio takes and trims room tone: removes head/tail silence or splits long files into individual phrases, applying configurable pre/post-roll margins and crossfades.

When: cleaning raw voice takes or splitting long sessions into individual phrases before creating delivery regions.

  1. Select items and click ANALYZE: inspects waveform without modifying items. Check Audio read status.
  2. PREVIEW draws temporary red preview regions; CLEAR PREVIEW removes them.
  3. APPLY performs cuts within a single Undo step.

Modes: Head/tail trim or Split internal silences; Original position or Sequence spacing. Presets: VO Smart, Gentle, Tight, Manual. Detailed guide →

Import Folders

Overview. Imports entire folder structures of audio or video files in order onto the timeline. Selected parent directory subfolders become timeline section markers, and media files become named regions with configurable gaps.

When: importing batches of organized files (e.g. 40 commercial spots across 4 languages) to deliver in the same directory structure. Render is triggered via Project Manager.

Project Manager

Overview. Delivery manager: creates export regions (one per take/file) and routes batch renders to correct destinations without altering original audio takes.

When: delivering numerous files requiring strict naming conventions and directory structures.

Create Regions

  • Source: Items (selected), Tracks (selected), Folder+, All. Only valid audio/video items are processed; empty items, notes, and MIDI are skipped. Video includes video files; Skip muted ignores muted clips.
  • File Gap: silence duration triggering a new region. Head/Tail Padding expands region boundaries without moving audio.
  • Naming: paste a list of names (one per line or ; separated) to apply sequentially; No. + name prefixes sequential numbers. The list starts from the region selected in the preview (the button says Incolla da 03; the same applies when you click in the names column to type). Svuota lista: one click undoes the last entry, double-click clears all names. Double-click to rename in preview; edits stay as drafts until applied. Closing with draft names asks: Yes applies them, No discards them and closes, Cancel goes back.
  • Create Regions updates existing regions and creates missing ones; Create Selected acts only on selected rows. Save applies only pending names to their corresponding regions, creates missing regions for those names, and saves the project without rebuilding the others. When closing with pending names, choose Yes to apply them and close or No to return to the Project Manager.

Prepare Mixdown

  • Section Selection: chooses marker section; encompasses regions up to the next marker.
  • Marker Lanes: Lane 1 = Mixdown/<marker>/; Lane 2 = subfolder; Lane 3+ = standard markers. Visible regions in Lanes 1 and 2 are included in render; regions in Lane 3+ or hidden regions are excluded.
  • Quick format settings (WAV/MP3, mono/stereo, sample rate). Render configures output path, $region wildcard, and opens REAPER Render dialog. + Queue queues batch jobs.
  • Log: writes history to Mixdown/Mixdown_History.csv. Index: creates Mixdown_Index.csv in section folders verifying rendered files.

A bar at the bottom of the window explains the button under the mouse pointer, also in Mixdown Settings and in the quick guide.

Project Viewer

Overview. Project table of contents: displays all markers and regions chronologically on separate rows. Click to navigate, double-click to rename, spacebar to audition. Selecting regions sets render bounds for Ctrl/⌘+Alt+R, and Minutes Report counts selections.

When: verifying section and region names prior to final render, or navigating large multi-hour timelines. Can be docked beside the arrange window.

Voice Minutes Report

Overview. Calculates total voice minutes: exact duration, rounded billable minutes, and estimated word counts. Counts selected regions, all regions, selected items, or tracks.

When: preparing billing invoices, client estimates, or auditing character workloads.

  • Only items with real audio takes are counted. Skip muted excludes muted clips.
  • Active format: choose HTML or CSV. The highlighted button and status label show the selected format; the choice is remembered. Each save updates only that format's history. HTML and CSV histories are separate.
  • Copy + HTML / CSV copies the report and opens the save confirmation in the active format.
  • Add to History: updates the active format's history without recounting existing entries.
  • Save Session: creates a separate file in the active format; general history stays unchanged.
  • Export HTML History to CSV: creates a separate CSV from the HTML history without changing the CSV history.

Probe Guard

Overview. Because the Probe measures actual output loudness, it must remain the last plugin on the bus. Probe Guard checks once per second that Voice Probe and Music Probe occupy the final slot, moving them back if plugins are inserted after them.

When: runs automatically with Chain Builder. Keeping the window open keeps the guard active.

ZP Shared Bus Plugins

ZP plugins communicate via shared memory (gmem=ZPVoiceoverSharedBus): each plugin reports real-time activity, the Probe measures real bus audio output, and Master Pro compares results against the target loudness engine to offer advisory suggestions. No plugin ever alters another plugin's DSP parameters. Installed via ReaPack in Effects/ZP_Paolo Balestri JSFX.

ZP BUS Chain

Purpose: Primary voice bus processor (dialogue, voiceover, dubbing). Combines Expander/Gate, De-Esser/Air, 1175, LA-2A, and Major Tom compressors, analog Brown stage, and safety Limiter.

Where to place: On Voice Bus (voice folder or master dialogue bus).

Key controls: Expander Thresh/Range, compressor RED/MAKEUP, Brown Drive/Mix, High Air, Limiter Ceiling/Release, module toggles. Broadcasts full telemetry to Shared Bus. The Brown Guard page has two separate switches: DYN (the dynamic correction that follows the Slope target) and EQ (the four manual EQ points); they work independently of the main Brown switch.

ZP Harmonic Space Carver

Purpose: Mix/music bed ducking assistant. Dynamically creates spectral and volume room under dialogue using voice-guided multibanda carving and VCA ducking, synchronized via timeline cues (#HSC).

Where to place: On Music Bus. Chain Builder places it here for Podcast and Commercial Spot profiles.

Key controls: VOICE: up to three sidechain sources (3/4, 5/6, 7/8), shown only when the track has those channels, each with ON, gain and a routing light; voice Thresh, RMS Stab, Hold, Lookahead (Anticipo). CARVER: Thresh, Intens, Low, Mid and High bands, Spread, Knee, Attack, Release; drag the crossovers on the BANDS map. VCA: Ceiling, Prio, Min Duck, Max Duck, Attack, Release, STD or GRADUAL return. OUTPUT: Mix, Glue, Out, In, Voice Ret. PARTENZA SCORE / FLAT / VOCAL sets the knobs as a starting point. SIMPLE shows the five main controls of the same engine; DOCK is a strip with status and cues to keep open while editing.

Quick return cues: ADD / REMOVE places a cue at the playhead (playing) or at the edit cursor (stopped). Select a cue in the row, then choose C/S/M/L; its choice stays with that marker when you move it. Ramp and Custom duration are also saved for the selected marker and recalled in the knobs when you select it again; Short is 0.5 s, Medium 1 s and Long 2 s. The sidechain is ignored during the Ramp and Hold; at expiry the detector resumes control of the ducking. DELETE removes the selected cues (Cmd/Ctrl+click or Shift+click for several), UNDO and CLEAR ALL manage the list. With the ZP Harmonic Space Carver Cue Navigator helper started when REAPER opens, every cue is also a #HSC marker in lane 4: move it by hand or with ripple and the Carver follows; new cues and deletions go through the Carver only (a #HSC deleted by hand comes back). Without the helper, per-marker presets are disabled.

Displaced cues: every cue remembers the voice beneath it. If that voice moves and the cue does not, the cue turns red and CUES DISPLACED appears at the top: one click on it (or the ZP HSC Cue - Riallinea key) moves every red cue back onto its voice. A single red cue offers REALIGN and KEEP HERE. Ctrl+Z undoes it.

Keyboard actions: ZP HSC Cue - Aggiungi o togli (add/remove), Successivo (next), Precedente (previous), Annulla (undo), Riallinea (realign). ZP HSC - Mostra tracce voce selects the tracks the Carver treats as voice: those that reach its sidechain.

Warnings: listen (CARV, VCA, ALL play only what is removed) blinks at the top and returns to OFF when the project is reopened; the meters always measure the real output. Min = Max means that with voice the music always drops by Max Duck and Ceiling and Prio do nothing: raise Min Duck.

ZP Voice-Music Probe

Purpose: Passive transparent shared bus metering probe. Never alters audio; accurately measures RMS, True Peak, crest factor, density, brightness, and speech activity.

Where to place: Absolute final slot on Voice Bus (Voice role) and Music Bus (Music role), guarded by Probe Guard.

Key controls: Role switch (Voice / Music), real-time meter display, Shared Bus gmem activity indicator.

ZP BrownSlope Prism

Purpose: Passive brown-slope analyzer: audio passes through untouched. It shows the spectrum with a 4.5 dB per octave slope compensation, so brown noise becomes a flat line. The two green lines are the -18 and -24 LUFS references; the orange curve is your audio. You are matched when the orange curve is flat and sits on the chosen line.

Where to place: At the end of the bus or track you want to compare with the brown reference, or on the Master.

Key controls: Average, Slope, Scale knobs (drag vertically; double click or right click = default); Ref., Shape, Reset, Calibrate, Default buttons. Shape removes the level difference and compares EQ only. Calibrate: play your reference loop with long average and press Calibrate; the curve is saved with the project, Default removes it.

Readings: Deviation in dB per zone (Lows, Low-mids, High-mids, Highs), residual slope (+ = brighter than brown, - = darker), level against the reference, result Matched / Close / No. JSFX view brings back REAPER's parameter list, readings included, for OSARA and screen readers.

Standalone SRT Tools

Accessible from ZP SRT or directly via the Action List.

01 · Video + SRT

Imports video and paired subtitle files: sets up video track and Rythmo Band Testi track with one text item per cue. Modes: Single, Folder batch, SRT/VTT only, Empty text track.

Excel script: wherever an SRT/VTT is requested you can pick an .xlsx file with timecodes. Columns are recognised from their headers (Timecode, Role, Reaction Sound, Translation, or Start, End, Text, Character, Reaction); each cue becomes CHARACTER: text, with the reaction appended; without an end column, a cue lasts until the next one. An .srt file with the same name is written next to the Excel file. If more than one sheet qualifies, or a sheet has several text columns (for example one per language), a small menu asks which sheet and which column to import: one at a time. If a filled row has an invalid time, the import stops and tells you which one. To choose sheet and columns by hand, or for legacy .xls files, use SRT Tools (26). In the prompters' free text, Load file… accepts the same .xlsx and inserts one cue per line, without times.

VTT and reactions: a WebVTT voice (<v Name>) becomes Name: text; formatting tags (italic, bold, colour) are removed; reactions written in angle brackets, such as <sospira>, stay in the text.

05 · SRT Management

Replaces or supplements subtitles in existing sessions: Replace SRT, Add language/reference, Batch matching. Archives previous items onto BKP backup tracks.

08 · Export SRT

Exports finalized SRT files from timeline text items. Times are calculated relative to each video or region start point, ready for distribution.

13 · SRT Item Info

Read-only inspector window that updates automatically when clicking different timeline items. Displays cue origin, binding status, and full text.

26 · SRT Tools (from text or translation)

Local browser utility to convert plain text scripts containing timecode into clean SRT files, with offset calibration. It also reads XLS and XLSX Excel files: pick the sheet and the columns (start, end, text, character, reaction) and whether to include characters and reactions; without an end column, durations are estimated up to the next line.

31 · SRT from Audio

Exports SRT files from take markers embedded inside selected audio items, capturing manual adjustments made in REAPER.

28 · Link Markers

Underlying engine for ZP Transcription stage 2: embeds SRT cues as take markers inside audio items. Details → From REAPER 7.86 each marker also carries the cue length (the item shows it as a tinted band) and SRT from audio (31) reads it back to write the exact end time; on earlier versions nothing changes.

34 · ZP Command Sets (Keyboard Shortcuts)

Switch keyboard shortcut layouts with one click: video editing layout, Pro Tools or Logic key habits, or custom setups. Open from the keyboard toolbar icon:

  • Activate: switches to selected set. Prompts to restart REAPER immediately or on next launch.
  • Inspect Layout: displays complete key-to-action list.
  • Export… (in a set's page): puts a copy of the set's .ReaperKeyMap file on the Desktop and shows it, to carry to another computer or keep as a copy. Sets saved here also include the mouse modifiers (a second file, .ReaperMouseMap, with the same name): they are saved, exported, imported and activated together with the keys; sets without that file leave mouse modifiers untouched.
  • AI Explanation (optional): generates plain-English summary of shortcut layout using local or cloud AI agents via ZP Speech.
  • Automatic Backup: archives current keys to Automatic Backup before any switch.
  • Save Current Keys… / Import File…: manage custom .ReaperKeyMap files.

35 · ZP Colors (Click & Color)

Color palette tool: choose one of six modes, select objects, then click a color. Auto colors selected items, markers, and regions together at the time of the click. Other modes target Item, Track, All (tracks and their items), Marker, or Region. One selector stays lit; selection alone never applies color. The tool has twenty colors and Remove Color. Fully reversible with Ctrl/Cmd+Z. Available as a floating window or optional toolbar ZP Colors.

37 · ZP Consolidate

One window with three independent commands, plus ? for the full explanation.

  • Consolida progetto (consolidate project): copies into Media, byte for byte, the files used by the project (audio, video, external MIDI, sources of every take) and its SRT/VTT files, then relinks the takes. It never converts or deletes the originals; it saves the project first and keeps a safety copy.
  • Pulisci Media (clean Media): finds the files in Media the project does not use and, if you confirm, moves them to a folder next to Media. Nothing is deleted.
  • Numera item (number items): renames the items on the selected tracks with the track name and a running number (Voice#1, Voice#2…), in the order they sit on the track. Useful to find the sequence again after heavy editing. Ctrl+Z undoes it.

Installation & Optional Components

Install and update via ReaPack: Extensions → ReaPack → Import repositories, paste https://github.com/capitanpaolone/zp-suite/raw/master/index.xml, browse packages, and install ZP Studio Suite.

33 Welcome (Installation Check): opens automatically on first tool launch or from the Action List. Verifies installed components:

  • Suite language: side-by-side buttons (Italiano | English). Applies immediately to windows, messages and guides opened after.
  • REAPER language: dropdown menu showing the active language pack (or Original (English)) from REAPER/LangPack. Selecting a pack shows a restart button to apply immediately. Prefer Italiano (ZP) for Italian: third-party packs translate three entries that REAPER matches in English ((delay %ds), sel_regions, sel_markers), and with those packs Render Queue jobs may fail to delete or run.
  • Toolbar & FX: Install runs tool 32. Restart REAPER to finalize.
  • Cue Navigator (Harmonic Space Carver helper): starts helper on launch.
  • ZP Speech: powers local Whisper transcription (MacWhisper on macOS or isolated OpenAI Whisper on macOS, Windows, and Linux) and translation.
  • SWS, js_ReaScriptAPI, OSARA: optional enhancements.
  • Item Markers: sets mouse modifier to protect take markers from accidental displacement.

Toolbar & FX: run 32 Install ZP Toolbar after installation to register action IDs and install FX chains. Details in toolbar guide.
