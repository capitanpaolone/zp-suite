ZP SOLO Recorder

Recording remote panel: what each button does.

Designed to record without constantly switching focus back and forth to the REAPER main window. Maintains exclusive track arming, numbers takes automatically, and keeps the few essential controls right under your fingers while reading.

SOLO Session or Remote Control

SOLO Recorder operates in two modes and remembers the choice per project.

  • SOLO Session: on first REC it creates the folder ZP SOLO SESSION with VO_MAIN, VO_INSERTS, VO_RETAKES, VO_ALT, and REF. It arms exclusively the selected track and disarms all others in the project, guaranteeing you record in one place only.
  • Remote Control: creates no tracks and touches no track arming. Records on tracks already armed by you in REAPER; warns if none is armed. When REC is pressed with no track armed, prompts which track to arm. To pick the track, open the input dropdown menu (button beside the IN meter). Use it when working in your existing project structure where you only need SOLO convenience controls (REC, NEXT TAKE, REMOVE TAKE, take names, regions, pre-roll, markers). RETAKE REGION, INSERT, and ALT TAKE are dimmed since they rely on dedicated SOLO session tracks.

When opened in a project: if empty, or already containing the ZP SOLO SESSION folder, starts in SOLO Session; if containing pre-existing tracks, starts in Remote Control. To toggle, use the header icons: folder (SOLO Session) and remote (Remote Control).

Input selection: in the Input & Monitoring section, next to the IN meter, the Input ▾ button indicates the physical input used by the target track (e.g. In 1 (Mic Pre 1) or In 1/2 stereo). Click to select another input.

Window Layout

Controls are organized in responsive zones. Resizing wraps zones naturally without overlapping controls. Three display views fit different workflows:

  • Mini: Transport, Input & Monitoring. Bare essentials while recording.
  • Compact: Adds Target Track (SOLO session only), Navigate & Mark, and a compact Navigator. The everyday session view.
  • Expanded: Adds Takes, Labels, and full-height Navigator. Comprehensive take direction.

The Four Recording Modes

ModeUsage
RECStandard recording on selected track from cursor position.
INSERTPunch-in insert recording: punches into silence or replaces a phrase without moving surroundings.
ALT TAKEAlternate take on dedicated ALT track to compare readings without committing immediately.
NEXT TAKEContinuous take recording: stops, indexes take, advances 5 seconds past audio end, and restarts recording automatically.

Safety and Undo

REMOVE TAKE removes the item from the timeline, never from disk. Recorded audio remains preserved inside the project's Media folder. Because operations run inside REAPER Undo blocks, Ctrl+Z (or Cmd+Z) instantly restores the item to the timeline.

Troubleshooting

REC will not start — Target track is not exclusively armed. Switch target track to re-arm cleanly.

Return knob disabled ("--") — No track is selected in REAPER. Select a track in REAPER once.

Monitor button says "auto" — Track is in REAPER auto-monitoring state; click to turn off.

REAPER window hidden — Click the header REAPER icon with upward arrow, or close SOLO Recorder.
