FFmpeg for ZP Remote

ZP Remote uses FFmpeg only to export the package: light video, cover image and audio guide. Importing does not need it. The Suite does not install FFmpeg: it detects it if present and tells you where it found it.

Do I have it?

Open 33 Welcome: the ZP Remote row reads FFmpeg <version>: <path>. If it says FFmpeg found but it does not run, the file is there but does not work on this computer (for example it is built for another processor): get a suitable one as described below.

To know which Mac you have: Apple menu › About This Mac. Chip Apple M1, M2, M3… means Apple Silicon; Intel processor means Intel.

Mac with Apple Silicon (M1, M2, M3, M4…)

  1. Install Homebrew from brew.sh (one line to paste in Terminal).
  2. In Terminal: brew install ffmpeg.
  3. FFmpeg ends up in /opt/homebrew/bin/ffmpeg: the Suite finds it by itself.

Mac with Intel processor

Homebrew no longer officially supports Intel Macs. The simplest way is a ready-made build:

  1. From evermeet.cx/ffmpeg (listed on the official FFmpeg page) download the ffmpeg zip and open it: you get a single file, ffmpeg.
  2. Copy it to /usr/local/bin. In Terminal: sudo mkdir -p /usr/local/bin then sudo cp ~/Downloads/ffmpeg /usr/local/bin/ (asks for your Mac password).
  3. If macOS blocks it on first use because it is not signed: System Settings › Privacy & Security › Open Anyway.

Alternatively: MacPorts, then sudo port install ffmpeg (it ends up in /opt/local/bin/ffmpeg, which the Suite finds by itself).

Windows

For now ZP Remote (import and export) works only on macOS: on Windows the Welcome marks it as not available. If you need FFmpeg anyway, ready-made builds are at gyan.dev or BtbN: extract the zip and add the bin folder to the Windows PATH.

Linux

From your distribution's package manager: Debian and Ubuntu sudo apt install ffmpeg; Fedora sudo dnf install ffmpeg (with RPM Fusion); Arch sudo pacman -S ffmpeg. It ends up in the PATH and the Suite finds it.

FFmpeg in another folder

In the Welcome press Choose FFmpeg… and point to the file. The choice is kept across Suite updates. If the file later disappears, the Suite goes back to the usual places.

After installing

Close and reopen the Welcome: the ZP Remote row should show version and path. No need to restart REAPER or the computer, or to change system settings. All builds: ffmpeg.org/download.html.
