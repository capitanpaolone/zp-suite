Link Markers

Imports dialogue lines from an SRT file as audio take markers in REAPER. Markers travel with the take when you move or split the item.

Toolbar icon

IdleHoverPressed

The icon shows a sheet with subtitle lines and a ring: the sheet represents SRT cues; the ring indicates that they are linked to audio as take markers. The three boxes are standard REAPER graphic states: normal, hover, and active. They do not indicate three different modes.

Before you start

  1. Select one or more audio items with an active take.
  2. For each audio file, keep an SRT alongside with the same base name, for example Interview.wav and Interview.srt. If not present, REAPER prompts you to select the SRT file (only when running 28 standalone; from the 29 ZP Transcription window, items without an adjacent SRT are skipped and listed).
  3. Check that SRT timestamps are referenced to the beginning of the original audio file.

Usage

  1. Normally you don't need to run it manually: the ZP Transcription window runs it, step Match from…. Standalone, it can be launched from the Action List (28_Collega_Marker); it does not have a toolbar button.
  2. If a take already contains take markers, choose Yes to replace them, No to skip that item, or Cancel to stop the operation before applying changes.
  3. When finished, review the summary: linked items, imported cues, and skipped items.
  4. To revert, use Undo in REAPER immediately: the import is a single Undo block.

What gets written

  • Each cue becomes a take marker: position = SRT start time; name = cue text. Multiple lines are merged into a single line.
  • Existing text and markers are replaced only after explicit confirmation.
  • An invalid SRT aborts preparation before modifying items.
  • It does not transcribe audio. Teleprompter text items are created by the next step, Send to teleprompter, which ZP Transcription launches automatically right after.

Limitations

  • Imports standard SRT format with timestamp HH:MM:SS,mmm or HH:MM:SS.mmm.
  • Uses the active take of each selected item; items without a take/source file are skipped.
  • For external SRTs, select the file matching the selected audio.
