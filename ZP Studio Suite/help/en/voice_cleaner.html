ZP Studio Suite - Silence Split / Voice Cleaner

Mini suite to clean leads and tails, separate long takes, and prepare voiceover files without manually editing every single pause.

Overview

  • Tail cleaning: removes long silence before and after a take.
  • Split long recordings: divides takes into phrases or spoken blocks.
  • Voiceover take preparation: creates tidy, renamed items with gentle fades.

Quick Workflow

  1. Select one or more audio items in the REAPER timeline.
  2. Select VO Smart.
  3. Click ANALYZE.
  4. Check segments, speech duration, and Audio OK status.
  5. Use PREVIEW to create temporary regions and verify splits.
  6. Click APPLY only when the result looks right.

Rule of thumb: if Audio read is not OK, the tool applies no modifications. First ensure audio can be read, then adjust parameters.

When Advanced is closed: advanced parameters do not act. Ignore click, Min segment, Merge gap, Sequence spacing, and File spacing take effect only when you expand Advanced Options / Output.

Modes

Head/Tail Trim

Trims the item from first speech to last speech. Ideal to remove head/tail room tone while keeping the performance body intact.

Split Internal Silences

Creates separate items for detected spoken sections and removes long pauses between sentences.

Presets

  • VO Smart: standard voiceover setting, great starting point.
  • Gentle: conservative, preserves more breathing space and tails.
  • Tight: aggressive, tighter cuts.
  • Manual: direct threshold control.

Parameters in Plain Terms

  • Auto/Manual: in Auto the tool estimates threshold from background noise; in Manual it uses your configured value.
  • Threshold: minimum speech level. Higher = fewer segments, lower = higher sensitivity.
  • Min silence: minimum silence length required to end a speech segment.
  • Gate open: minimum sound duration before speech is recognized.
  • Gate hold: duration gate remains open during brief inter-word pauses.
  • Ignore click: Advanced option. At OFF keeps all transient events; increasing ignores very short noises, mouth clicks, and isolated thumps.
  • Min segment: Advanced option. At OFF does not filter by minimum duration; increasing discards tiny fragments.
  • Merge gap: Advanced option. At OFF does not merge neighboring segments; increasing fuses segments separated by brief pauses.
  • Pre-roll: margin retained before speech start.
  • Post-roll: margin retained after speech end.
  • Fade: short crossfade applied to created items.
  • File spacing: Advanced option. Gap between created takes when choosing Sequence spacing. Not applied with Original position or when Advanced is closed.

Knobs and Controls

  • Drag a knob up or down to adjust values.
  • Hold Shift for fine adjustments.
  • Double click or right click a knob to reset to the active preset default.
  • Mouse wheel adjusts the value when hovering over a knob.

Practical Examples

Long file with many separate lines

Use VO Smart and Split Internal Silences. If lines are broken into fragments, raise Gate hold; if needed, open Advanced and test Merge gap.

Clean head and tail only

Use Head/Tail Trim. The tool keeps everything between the first and last speech events.

Tool cuts too aggressively

Try Gentle, lower threshold, or raise Post-roll, Gate hold, or Merge gap.

No segments detected

Verify that Audio OK is green. Then try a lower threshold or the Manual preset.

Too many segments created

Raise Min silence, Gate hold, or Merge gap. If room noise triggers false positives, raise threshold.

Safety Guarantees

  • PREVIEW creates temporary red regions ZPSS22_PREVIEW on the timeline.
  • PREVIEW is available only with Original position. In Sequence spacing, placement is computed upon Apply.
  • CLEAR PREVIEW removes only these temporary preview regions.
  • APPLY operates within a REAPER Undo block.
  • Without valid segments, the tool neither alters nor removes items.
  • A single Undo step reverts the entire operation.

Troubleshooting

  • Unreadable audio: verify selected item is audio and has an active take.
  • Max peak -120 dB: REAPER returns all zero samples; check offline media, muted take, or missing source.
  • No speech detected: audio read cleanly but threshold/gate detects no sections; lower threshold.
  • Threshold too high: few or no sentences recognized.
  • Threshold too low: room tone and breaths turned into segments.
  • Offline item: relink media in REAPER and click ANALYZE again.
  • MIDI / non-audio take: select an actual audio item.
  • Missing file: check source path in Project Bay / Media Bay.

Debug

The Debug toggle is disabled by default. When OFF, the console stays closed and compact telemetry is shown. When ON, detailed AudioAccessor calls, windows, peak/RMS data, and technical diagnostic logs are printed to the console.
