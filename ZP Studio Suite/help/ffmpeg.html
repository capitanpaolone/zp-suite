FFmpeg per ZP Remote

ZP Remote usa FFmpeg solo per esportare il pacchetto: video leggero, immagine di copertina e guida audio. Per importare non serve. La Suite non installa FFmpeg: lo riconosce se c'è e ti dice dove l'ha trovato.

Ce l'ho?

Apri 33 Benvenuto: nella riga ZP Remote leggi FFmpeg <versione>: <percorso>. Se dice FFmpeg trovato ma non parte, il file c'è ma non funziona su questo computer (per esempio è per un altro processore): scaricane uno adatto con le indicazioni qui sotto.

Per sapere che Mac hai: menu Apple › Informazioni su questo Mac. Chip Apple M1, M2, M3… vuol dire Apple Silicon; Processore Intel vuol dire Intel.

Mac con Apple Silicon (M1, M2, M3, M4…)

  1. Installa Homebrew da brew.sh (una riga da incollare nel Terminale).
  2. Nel Terminale: brew install ffmpeg.
  3. FFmpeg finisce in /opt/homebrew/bin/ffmpeg: la Suite lo trova da sola.

Mac con processore Intel

Homebrew non supporta più ufficialmente i Mac Intel. La strada più semplice è una versione già pronta:

  1. Da evermeet.cx/ffmpeg (indicata dalla pagina ufficiale di FFmpeg) scarica lo zip di ffmpeg e aprilo: ottieni un solo file, ffmpeg.
  2. Copialo in /usr/local/bin. Nel Terminale: sudo mkdir -p /usr/local/bin e poi sudo cp ~/Downloads/ffmpeg /usr/local/bin/ (chiede la password del Mac).
  3. Se al primo uso macOS lo blocca perché non firmato: Impostazioni di Sistema › Privacy e sicurezza › Apri comunque.

In alternativa: MacPorts e poi sudo port install ffmpeg (finisce in /opt/local/bin/ffmpeg, che la Suite trova da sola).

Windows

Per ora ZP Remote (importa ed esporta) funziona solo su macOS: su Windows il Benvenuto lo segna come non disponibile. Se FFmpeg ti serve comunque, le versioni pronte sono su gyan.dev o BtbN: estrai lo zip e aggiungi la cartella bin al PATH di Windows.

Linux

Dal gestore dei pacchetti della distribuzione: Debian e Ubuntu sudo apt install ffmpeg; Fedora sudo dnf install ffmpeg (con RPM Fusion); Arch sudo pacman -S ffmpeg. Finisce nel PATH e la Suite lo trova.

FFmpeg in un'altra cartella

Nel Benvenuto premi Scegli FFmpeg… e indica il file. La scelta resta salvata anche dopo gli aggiornamenti della Suite. Se poi il file sparisce, la Suite torna a cercarlo nei posti soliti.

Dopo l'installazione

Chiudi e riapri il Benvenuto: la riga ZP Remote deve mostrare versione e percorso. Non serve riavviare REAPER né il computer, né cambiare impostazioni di sistema. Tutte le versioni: ffmpeg.org/download.html.
