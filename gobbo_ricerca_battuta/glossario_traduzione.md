# Glossario Traduzione — ZP Studio Suite

Questo glossario fissa i termini tecnici e le convenzioni per la traduzione della ZP Studio Suite (A) e del Language Pack di REAPER (B).

## Regole generali
1. **Termini REAPER invariati (in inglese)**:
   - item
   - take
   - marker
   - take marker
   - region
   - track
   - render
   - ripple
   - trim
   - loop
   - edit
   - FX
   - bus
   - send
   - toolbar
   - SRT

2. **Nomi strumenti ZP**:
   - **Gobbo -> Teleprompter**: confermato da Paolo (2026-10-09). Nella versione inglese si traduce "Gobbo" con "Teleprompter", lasciando "Gobbo" solo quando ci si riferisce al nome proprio del file/modulo nel codice o nei comandi interni.
   - Gobbo Verticale -> Vertical Teleprompter
   - Gobbo Orizzontale -> Horizontal Teleprompter
   - Traccia gobbo -> Teleprompter track
   - Altri nomi propri (SOLO Recorder, Probe Guard, Chain Builder, Stagekeeper, BrownSlope Prism, Harmonic Space Carver) restano invariati.

3. **Sigle e tasti**:
   - Sigle invariate: dB, dBFS, LUFS, RMS, PK, VCA, SC, EQ, IN, OUT, TC, REC, PLAY, STOP, PAUSA, PRE, GUID, WAV, MP4, CSV, PID, IP, QR, SWS, OSARA.
   - Tasti invariati: Enter/Invio, Esc, Space, Shift, Ctrl, Cmd, Opt/Alt.

4. **Segnaposto intatti**:
   - `%s`, `%d`, `%f`, `%.1f`, `\n`, `\t` e caratteri di formattazione non devono essere alterati o riordinati impropriamente.
   - Nomi di file, percorsi e chiavi di configurazione non si traducono.

5. **Convenzioni verbi e pulsanti (italiano -> inglese)**:
   - Salva -> Save
   - Annulla -> Cancel (o Undo nel contesto di cronologia)
   - Ripeti -> Redo
   - Chiudi -> Close
   - Applica -> Apply
   - Sostituisci -> Replace
   - Cerca / Trova -> Search / Find
   - Avanti / Successivo -> Next
   - Indietro / Precedente -> Previous
   - Rinomina -> Rename
   - Elimina / Cancella -> Delete / Remove
   - Mostra -> Show
   - Nascondi -> Hide
   - Aggiorna -> Update / Refresh
   - Trascrivi -> Transcribe
   - Ritrascrivi -> Retranscribe
   - Collega -> Link
   - Sincronizza -> Synchronize / Sync
   - Attiva -> Enable / Activate
   - Disattiva -> Disable / Deactivate
   - Impostazioni -> Settings
   - Aiuto / Guida -> Help
